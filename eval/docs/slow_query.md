# 慢查询排查

模块：performance
标签：slow_query

## 能力说明
- 慢查询 支持 执行计划分析。
- 慢查询 支持 索引检查。
- 慢查询 支持 统计信息刷新。
- 慢查询 支持 SQL 改写。

## 故障关系
- 慢查询 可能原因 缺少索引。缺少索引 导致 全表扫描。
- 慢查询 可能原因 统计信息过期。统计信息过期 导致 执行计划不准。
- 慢查询 可能原因 锁等待。锁等待 导致 响应时间增加。
- 慢查询 可能原因 work_mem 过小。work_mem 过小 导致 排序落盘。

## 关键词
排查该主题时经常出现这些术语：EXPLAIN、ANALYZE、seq scan、work_mem。

## 处理建议
建议先确认模块和标签，再结合系统视图、执行计划、参数配置和历史变更记录进行排查。
