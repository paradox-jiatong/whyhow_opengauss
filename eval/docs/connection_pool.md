# 连接数与连接池

模块：connection
标签：connection

## 能力说明
- 连接池 支持 最大连接数控制。
- 连接池 支持 空闲连接回收。
- 连接池 支持 连接复用。
- 连接池 支持 会话超时配置。

## 故障关系
- 连接池 可能原因 连接泄漏。连接泄漏 导致 连接数耗尽。
- 连接池 可能原因 池大小过小。池大小过小 导致 请求排队。
- 连接池 可能原因 空闲事务。空闲事务 导致 锁资源占用。
- 连接池 可能原因 认证失败。认证失败 导致 连接建立失败。

## 关键词
排查该主题时经常出现这些术语：max_connections、idle timeout、pool size、session。
