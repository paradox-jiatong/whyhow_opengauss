# 备份恢复

模块：reliability
标签：backup

## 能力说明
- 备份恢复 支持 全量备份。
- 备份恢复 支持 增量备份。
- 备份恢复 支持 时间点恢复。
- 备份恢复 支持 备份校验。

## 故障关系
- 备份恢复 可能原因 归档日志缺失。归档日志缺失 导致 时间点恢复失败。
- 备份恢复 可能原因 备份文件损坏。备份文件损坏 导致 恢复中断。
- 备份恢复 可能原因 权限不足。权限不足 导致 备份任务失败。
- 备份恢复 可能原因 存储空间不足。存储空间不足 导致 归档失败。

## 关键词
排查该主题时经常出现这些术语：gs_basebackup、WAL、PITR、archive_mode。

## 处理建议
建议先确认模块和标签，再结合系统视图、执行计划、参数配置和历史变更记录进行排查。
