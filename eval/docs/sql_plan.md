# 执行计划与优化器

模块：optimizer
标签：sql_plan

## 能力说明
- 执行计划 支持 Join 顺序分析。
- 执行计划 支持 谓词下推。
- 执行计划 支持 索引选择。
- 执行计划 支持 代价估算。

## 故障关系
- 执行计划 可能原因 统计信息不准确。统计信息不准确 导致 错误 Join 顺序。
- 执行计划 可能原因 函数包裹列。函数包裹列 导致 索引失效。
- 执行计划 可能原因 隐式类型转换。隐式类型转换 导致 过滤条件失效。
- 执行计划 可能原因 返回行估计偏差。返回行估计偏差 导致 计划选择错误。

## 关键词
排查该主题时经常出现这些术语：nested loop、hash join、predicate pushdown、cost。

## 处理建议
建议先确认模块和标签，再结合系统视图、执行计划、参数配置和历史变更记录进行排查。
