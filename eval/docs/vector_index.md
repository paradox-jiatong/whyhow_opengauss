# 向量检索与索引

模块：vector
标签：vector_index

## 能力说明
- 向量检索 支持 Embedding 入库。
- 向量检索 支持 Top-K 相似度查询。
- 向量检索 支持 向量距离计算。
- 向量检索 支持 元数据过滤。

## 故障关系
- 向量检索 可能原因 维度过高。维度过高 导致 计算开销增加。
- 向量检索 可能原因 过滤条件过宽。过滤条件过宽 导致 候选集变大。
- 向量检索 可能原因 索引缺失。索引缺失 导致 召回延迟增加。
- 向量检索 可能原因 向量未归一。向量未归一 导致 相似度偏差。

## 关键词
排查该主题时经常出现这些术语：embedding、Top-K、cosine、metadata。
