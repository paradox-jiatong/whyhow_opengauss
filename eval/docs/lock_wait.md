# 锁等待排查

模块：concurrency
标签：lock_wait

## 能力说明
- 锁等待 支持 pg_locks 查询。
- 锁等待 支持 pg_stat_activity 分析。
- 锁等待 支持 阻塞会话定位。
- 锁等待 支持 事务超时控制。

## 故障关系
- 锁等待 可能原因 长事务。长事务 导致 锁释放延迟。
- 锁等待 可能原因 DDL 操作。DDL 操作 导致 表级锁竞争。
- 锁等待 可能原因 热点更新。热点更新 导致 行锁冲突。
- 锁等待 可能原因 未提交事务。未提交事务 导致 会话阻塞。

## 关键词
排查该主题时经常出现这些术语：pg_locks、pg_stat_activity、locktype、wait_event。

## 处理建议
建议先确认模块和标签，再结合系统视图、执行计划、参数配置和历史变更记录进行排查。
